# Ahmed Lab

Instructional site with information on how to replicate behavioral rigs for *Drosophila melanogaster* built by the Ahmed Lab

## Rigs
Top-down behavior
- Prometheus
- Epimetheus
- N-Metheus

Fly-on-ball
- Atlas-Motorized
- Atlas-Maui (2P Microscopy)
- Atlas-Courtship

Please visit oahmedlab.github.io to access the repo website
